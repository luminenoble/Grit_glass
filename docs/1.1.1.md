# 1.1.1 Windows 桌面端、自由散落任务墙与局域网同步设计

本文是 1.1.1 的功能、视觉与跨端架构设计方案。其中 **P0、P1 已在 1.1.1.1 实现并并入 [项目概览.md](项目概览.md)**，P2 尚未实现；待 P2 全部落地并并入后删除本文。

## 1. 产品定位与端侧分工

手机竖屏（~360 dp）天然不适合承载多列卡片墙，而项目本身已基于 Compose Multiplatform 具备 `jvm()` 目标与现成桌面入口。1.1.1 将重心明确为**双端互补**：

- **Windows 桌面端（规划与全局白板主场）**：
  - 核心视图为**自由散落任务墙（Spatial Wall）**，利用宽屏与鼠标（悬停、拖拽、平移缩放）把待办像实体暖纸便签一样摆在桌面上。
  - Task 页沿用并强化已有的宽屏多面板看板（`ExpandedTasksView`）。
- **Android 移动端（随身执行与提醒终端）**：
  - 聚焦 **Task 页（类别列表 + Today）**、通知提醒与桌面 Glance 小组件，适合外出快速查看与勾选完成。
  - 手机端 Overview **不再强行承载网格任务墙**，保留简洁的 **Later / Done** 视图（可选附带按日期排序的简洁临期清单），彻底告别窄屏卡片截断。
- **双端数据互通**：采用**方案 A（局域网一键互传）**，零公网服务器成本，完整复用现有的 `TaskBackup` v2 JSON 协议与整库事务替换。

## 2. 核心视觉规范（共享 UI 与桌面纸面语言）

参考 Apple iOS 26 Liquid Glass HIG、Kyant `AndroidLiquidGlass` 与 Warm Paper Bento 立体卡片设计：

1. **双层介质分离**：液态玻璃只用于浮动控件（导航条、胶囊工具栏、`TaskLens` 预览、弹窗），内容卡片始终为不透明暖米纸面；避免玻璃叠玻璃，保证交互文字 ≥ 4.5:1 对比度。
2. **任务墙双维度对调**：
   - **大小 = 重要度（`Priority`）**：重要事情稳定占据更大的视觉面积。
   - **深浅 = DDL 紧迫度（`deadline - today`）**：期限越近纸色越浓重沉稳，不依赖把自定义文字淡化 68% 来区分层级。
   - **海拔 = 交互与状态**：卡片具备暖褐扩散外影 + 顶部亮白受光切边，沉底任务做内凹质感。
3. **同心几何**：统一遵循 `外圆角 = 内圆角 + 内边距`。

## 3. 分级实施路线（P0 → P1 → P2）

### P0：共享 UI 止血修复（颜色、截断、防碰撞）— 已完成（1.1.1.1）

1. **自定义颜色与对比度保护**
   - 取消当前 `WallTile` 中对 `LOW`/`NORMAL` 标题颜色向纸面混合 48%–68% 的做法；文字始终保持高对比度（对用户自选的 `titleColor` 做感知亮度底线钳制，防止浅色文字融进米纸）。
   - 清理 `TaskCard`、`TaskUpsertSheet`、`SectionEditor` 中 Section 默认色硬编码的 `Color.Black`，统一改为 `MaterialTheme.colorScheme.onSurface`（`#3C3A36`）。
   - 在 `GritBaseColors` 中显式补充与暖米色调一致的 `error`（对齐 `GlassTokens.Danger` `#9A3B30`）及容器色，替换 Material 默认高饱和亮红，并清理 `GritTokens.kt` 残留的 Ant Design 高饱和色。
   - 类别托盘（`CategorySelector`、`CategoryFilter`）芯片文字统一使用 `onSurface` / `SecondaryText`，**仅保留左侧 8–10 dp 的彩色圆点**表示类别色。

2. **字体截断与字号层级修复**
   - `TaskCard`：`task.description` 补充 `overflow = TextOverflow.Ellipsis`；`"X/Y Section"` 入口显式设为 `MaterialTheme.typography.labelMedium` + `SecondaryText`；展开后的 Section 列表去掉默认多行 `basicMarquee()`，改用 `maxLines = 1, overflow = TextOverflow.Ellipsis`。
   - `GlassSegmented`：选项文字补充 `overflow = TextOverflow.Ellipsis` 与紧凑水平边距回退，避免长文案在窄空间硬裁切。
   - 类别名称（`CategoryToggleButton`、`ExpandedTasksView` 面板标题）：补充 `maxLines = 1, overflow = TextOverflow.Ellipsis`。
   - 卡片标题文本关闭 Android 多余上下留白（`includeFontPadding = false`），防止大字号时底部像素被裁。

3. **底部悬浮层防碰撞**
   - 将 `ArchiveToast` 的垂直位置上移到 `GlassFab` / `CardTapKeys` 之上（如 `LocalFloatingBarInset.current + GlassMetrics.Primary + 24.dp`），避免窄屏下与右下角展开按钮重叠。

### P1：形状统一、立体卡片与排版精致化 — 已完成（1.1.1.1）

1. **同心圆角与几何清理**
   - 收拢 `GritRadius`、`ListItemExt.kt`、`GlassShapes` 为单一规范：
     - 修正 `GlassToolbar` 外圆角为 `28 dp`（匹配内部 `44 dp` 圆形按钮 + `6 dp` 内边距）。
     - 统一卡片圆角：`12 dp` / `16 dp`（对应单行/双行），消除弹窗列表内层圆角冲突。
   - 移除残留的 Material Expressive 异形（`MaterialShapes.Pill` 图标底托、`ButtonShapes` 按压形变），统一为纯粹圆形/胶囊与 `GlassPressIndication`。

2. **任务墙卡片立体化（Tactile Paper Elevation）**
   - **立体三要素**：外侧暖褐柔阴影（`GlassTokens.Shadow` `#5B4B3A`）+ 内侧顶部/左上 `0.5–1 dp` 亮白受光描边 + 底部微暗收口边。
   - **海拔分层**：
     - `HIGH` 大块：更深的暖褐柔影与清晰高光边，呈现明显抬升感。
     - `NORMAL` / `LOW` 块：轻量微抬，贴近画布。
     - **沉底（`hasSunk`）任务**：**内凹（Recessed）质感**——移除外阴影，改为顶部内侧细暗影 + `#E3DCCE` 深米底色。

3. **顶栏与设置页细节整理**
   - 顶栏 `LargeFlexibleTopAppBar` 副标题去掉过重的 `flexFontRounded()`（`weight = 700`），改用正文字体常规字重 + `SecondaryText`，突出主标题。
   - `RootPage` 的 `WallSettingsGroup` 去掉三个数字输入框内的 `"days"` 后缀（写入说明文案），释放横排空间。
   - `LookAndFeelPage` 顶栏标题统一 `flexFontEmphasis()`，字体列表接入 `GlassGroup` 并支持整行点击。

### P2：Windows 桌面端落地、自由散落任务墙与局域网互传

#### 1. Windows 桌面端模块改造

当前 `:shared:core` 与 `:shared:ui` 已支持 `jvm()`，可从 `webDemo/jvmMain` 独立或演化为正式 `:desktopApp` 模块（最终可通过 Compose Desktop `packageExe` / `packageMsi` 打包）：

- **共享持久化下沉**：将 `:androidApp` 中与 Android `Context` 无关的数据库定义（Room 3 KMP + `sqlite-bundled`）、DAO、仓库核心逻辑及 `DataStore` Preferences 抽入共享模块（如 `:shared:data`），`TasksRepository` 的通知与小组件刷新改为可注入的平台回调（桌面端留空或接系统托盘提醒）。
- **数据目录与文件对话框**：Windows 本地数据存于 `%APPDATA%\GritGlass\`；备份导入导出已使用跨平台 `FileKit`，无需重写即可弹出 Windows 原生文件窗口。
- **桌面端玻璃增强（可选）**：在 `GlassLens.jvm.kt` 中利用 Skiko `ImageFilter.makeRuntimeShader`（SkSL）实现与 Android 13+ 等价的边缘折射与色散效果；支持窗口大小记忆与基础快捷键（如 `Ctrl+N` 新建任务、`Esc` 关闭预览）。

#### 2. 桌面自由散落任务墙（Spatial Wall）

手机端 Overview 退化为简洁的 **Later / Done** 列表；桌面端（Expanded / Desktop）启用真正的**自由白板任务墙**：

- **画布与自由摆位**：
  - 一张可平滑平移（中键/触控板/空白处拖拽）与适度缩放的暖米纸桌面，支持 2D 无限画布或宽幅工作区。
  - **支持鼠标左键自由拖拽卡片摆位**，并配轻量的 `±1.5°~2.5°` 自然微倾角，呈现桌面便签感。
  - **鼠标微交互**：Hover 悬停时卡片平滑回正至 `0°` 并微微浮起（投影加深）；左键单击直接胀开 `TaskLens` 玻璃预览，双击或右侧按钮进入编辑。
- **自动防重叠与本地坐标存储**：
  - **坐标不入主备份**：每张卡片的 `(x, y, angle)` 存在 Windows 本地的轻量布局缓存（以 `task.id` 为键，保存在桌面本地 JSON / DataStore），**不修改 `TaskBackup` v2 数据结构**，保证与 Android 端互传 100% 兼容。
  - **新任务落位算法**：新增或同步过来的无坐标任务，按重要度与 DDL 紧迫度采用**螺旋空位搜索 / 碰撞排斥算法**自动落在不重叠的空位上；已删除/归档任务的坐标定期清理。
  - **快捷整理动作**：顶部工具栏提供“**Scatter（自然散落重排）**”“**Cluster by Category（按类别聚拢）**”“**Pull Urgent Center（紧迫向中心汇聚）**”等一键布局动作，既能随意摆也能一键收拾。
- **大小 = 重要度，深浅 = DDL 紧迫度**：
  - **卡片尺寸（宽屏彻底消除截断）**：
    - `HIGH`（或已过期）：约 `300 × 150 dp`（展示标题、描述摘要、DDL、Section 进度）
    - `NORMAL`（`isToday` 至少此档）：约 `230 × 112 dp`
    - `LOW`：约 `180 × 92 dp`
  - **纸面深浅（随 DDL 逼近加深）**：
    - 无 DDL：纯净亮米纸 `#FBF8F3`
    - 剩余 > `c` 天：极淡暖调
    - 剩余 `b+1` ~ `c` 天：浅暖沙色加深
    - 剩余 `a+1` ~ `b` 天：温润琥珀浅染
    - 剩余 ≤ `a` 天或已过期：浓郁焦糖/砖褐浅染 + 左侧墨色/砖红标记
  - `task.titleColor` 与 `category.titleColor` 作为标题/角标点缀色清晰呈现，不再被纸面色冲淡。

#### 3. 局域网一键互传（方案 A）

完全复用现有的 `TaskBackup`（JSON v2）与 `TasksRepository.replaceData(backup)`，在局域网内零服务器完成双端数据同步：

- **角色与传输协议**：
  - **Windows 端内置微型 HTTP Server**（使用 JDK 自带 `com.sun.net.httpserver.HttpServer`，无需引入重型服务端框架），点击“LAN Sync”时开启临时服务，绑定随机高端口并生成一次性 6 位 PIN（`Authorization` / Query Token 校验）。
  - 界面展示本机局域网 IP + 端口 + PIN 的**二维码**（同时支持手动输入 IP 与 PIN，后续可补 UDP 局域网自动发现）。
  - 提供两个核心接口：
    - `GET /snapshot/meta`：返回本机设备名、`exportedAt`、Category 数量、Task 数量（用于同步前比对）。
    - `GET /snapshot`：下载完整 `TaskBackup` v2 JSON（Windows → Android 拉取）。
    - `POST /snapshot`：上传 `TaskBackup` v2 JSON 并由 Windows 端执行 `TaskBackup.decode` 校验与 `replaceData`（Android → Windows 推送）。
- **Android 端同步入口**：
  - 在 Setting → Backup 页面新增“**LAN Sync with Desktop**”，扫码或输入配对码连接后，同屏对比手机与电脑的**最新导出/修改时间、类别数、任务数**，由用户明确点击：
    - **Push to Windows**（手机覆盖电脑）
    - **Pull from Windows**（电脑覆盖手机）
- **安全与防呆保护**：
  - **本地偏好不覆盖**：字体、窗口尺寸、桌面画布坐标、`WallSettings` 等保留在各自设备本地。
  - **同步前自动保护快照**：任意一端被覆盖前，自动将当前库导出一份带时间戳的回滚快照到本地缓存目录（保留最近 3–5 份），若误点覆盖方向可立即恢复。
  - **过期会话自动关闭**：Windows 端同步服务默认在页面关闭或超时（如 10 分钟无操作）后自动停止监听。
