# 项目概览

Grit Glass 的现行结构，对应 1.0.0（2026-10-27）。构建与发布见 [开发与发布.md](开发与发布.md)。改动这里描述的内容时，在同一个提交里更新本文。

## 1. 应用

纯待办应用，从 Grhinet 6.2.4 分出，去掉了 Rhine 场景和插图；Grhinet 本身在 [luminenoble/Grit](https://github.com/luminenoble/Grit) 单独维护。两者都基于上游 [Grit](https://github.com/shub39/Grit)（GPL-3.0）。

- 显示名 Grit Glass，`applicationId` 为 `io.github.luminenoble.gritglass`，可与 Grhinet 同时安装。Kotlin 包名和文件路径与 Grhinet 保持一致，方便两个仓库互相 `cherry-pick` 共用部分的修复（本仓库的 `grhinet` remote 指向 Grhinet）。
- 底部导航：**Task / Setting**。
- 已从上游移除且不恢复：Habit、统计栏目、AI 任务分解、动态取色与整体调色、深色主题。

| 项目 | 现状 |
| --- | --- |
| 语言 / UI | Kotlin 2.4、Compose Multiplatform 1.11.1、Material3 Expressive |
| 模块 | `:androidApp`（Room、DataStore、Glance 小组件、平台实现）、`:shared:core`（模型与接口）、`:shared:ui`（commonMain UI）、`:webDemo`（JVM / Wasm 演示桩，需保持可编译） |
| Android | minSdk 29、target / compile 37 |
| 主题 | 固定米色浅色主题 + 液态玻璃控件（见第 4 节） |

## 2. 数据

以 `Category → Task → Section` 组织。

| 对象 | 主要字段 |
| --- | --- |
| Category | `name`、`description`、`orderIndex`、`titleColor`、`hideCompleted`（只作用于 Task 列表和小组件）、`createdAt/updatedAt` |
| Task | `categoryId`、`title`、`description`、`orderIndex`、`titleColor`、`isCompleted`（手动）、`isToday`、`reminder`、时间戳 |
| Section | `taskId`、`title`（空则为 `unname`）、`content`、`orderIndex`、`completedOn`（null 为未完成）、`titleColor`、时间戳 |

规则：

- ID 固定，不随排序改变；`orderIndex` 在同一父级内从 0 连续；新增一律尾插；移动和删除在事务内补齐排序。
- Section 完成由 `completedOn` 推导：勾选填当天，可改为过去日期，不能是未来；取消完成清空。同一天允许多条。
- Task 与 Section 的完成互不影响。已完成 Task 不触发提醒，重新打开时只恢复仍在未来的提醒。
- **颜色** `titleColor`：null 为默认；`#RRGGBB` 为纯色；2–5 个以逗号分隔为从左到右的渐变（如 `#C0392B,#1E6FD9`）。仓库写入、备份导入都校验格式（`shared/core/.../tasks/TaskRules.kt`）。颜色原样显示，不做对比度修正。

**数据库** `grit_glass_database`，Room，`SCHEMA_VERSION = 1`（`androidApp/.../tasks/data/database/`）：`categories`、`tasks`、`sections` 三表，外键级联。schema 变化时提高版本并加迁移（见开发与发布）。

**备份**：`TaskBackup`（`shared/core/.../settings/backup/TaskBackup.kt`），JSON 中 `format = "grit_rhine"`、`formatVersion = 1`，与 Grhinet 的备份格式相同，两边导出的文件可以互相导入。Section 嵌套在 Task 内。导入先校验（ID、引用、颜色、日期、连续排序）、展示数量，确认后在一个事务内整库替换；失败不改动现有数据。备份不含本机设置。

## 3. Task 页与 Setting

- Task 页：顶栏（删除已完成、调整顺序）、类别托盘（今天、各类别、新增 / 编辑类别）、任务卡列表、右下角添加任务。任务卡点按切换完成，长按拖动排序。
- 任务详情、新建任务、类别编辑是整页编辑器，用一份草稿，保存时整体提交，返回时有未保存提示。Section 列表有“调整顺序”切换：默认右侧为编辑图标，调整时为拖动手柄，也可输入目标序号。
- 颜色选择 `ColorPickerDialog`：纯色 / 渐变（至多 5 色）、色环与亮度、R/G/B 与 HEX 输入、复制粘贴（同时写入应用内与系统剪贴板，粘贴优先读系统剪贴板）。Category、Task、Section 表单共用 `TitleColorRow`。
- Setting：通知、完成后排序、小组件字号、启动页面、24 小时制、外观（字体、“降低透明度”）、备份、关于、更新内容、语言。

## 4. 液态玻璃

代码：`shared/ui/.../theme/LiquidGlass.kt`（材质、尺寸、采样）、`theme/GlassPress.kt`（按压）、`androidMain/.../theme/GlassLens.android.kt`（透镜着色器）、`components/glass/GlassComponents.kt`（按钮、开关、分段等）。

**原则**：玻璃只用于浮在内容上的控件；任务卡、设置行是不透明的纸面（`Content` 档）。玻璃靠光来成形：透镜边、高光边、形状外侧的暖褐阴影，底色很淡。按下时被光照亮，任何时候都不变暗。

| 档位 | 用途 | 底色（有采样 / 无采样） | 模糊 | 透镜边带 | 色散 |
| --- | --- | --- | --- | --- | --- |
| `Thin` | 导航胶囊、添加任务、图标按钮、类别芯片与托盘、分段、提示 | `#FBF8F3` 0.08 / 0.36 | 1.5 dp | 14 dp | 0.35 |
| `Regular` | 菜单、滚动后的顶栏 | `#FBF8F3` 0.55 / 0.82 | 18 dp | 10 dp | 0 |
| `Thick` | 对话框、底部表单 | `#F2EDE5` 0.82 / 0.95 | 30 dp | 无 | 0 |
| `Content` | 任务卡、设置分组行 | 不透明 | 无 | 无 | 0 |

- 一个玻璃面由下到上：形状外侧的暖褐 `#5B4B3A` 阴影（模糊后裁掉形状内部，所以不会从下面把玻璃染灰）→ 背景采样（先模糊，再过透镜）→ 底色 → 顶部光泽 → 底部内侧聚光 → 左上最亮的高光边 → 外细线。
- **透镜**（Android 13+，AGSL `RuntimeShader`）：参考 Apple Liquid Glass 和 Kyant 的 AndroidLiquidGlass。用圆角矩形 SDF 求到边缘的距离，在宽 `bevel` 的边带里，玻璃表面按四分之一圆下落，采样点沿法线向内偏移 `bend·(1−√(1−x²))`（x 在边缘为 1，`bend = 1.25·bevel`）；红、蓝通道分别多 / 少偏移 `dispersion` 倍做色散；整体饱和度 ×1.25；边带按下落量提亮 0.22。着色器只编译一次，所有玻璃共用。
- Android 12 只有模糊没有透镜；Android 10–11、“降低透明度”（全部不透明）、独立窗口（`Dialog`、`Popup`、`ModalBottomSheet` 采样不到主窗口）都不采样，用无采样底色；Android 12 以下阴影改用平台阴影。
- **采样源**：`Modifier.glassSource` 每次绘制把内容记录进图层，采样它的玻璃不能画在它里面。紧凑布局里整个 `NavDisplay` 是导航胶囊的源，任务列表的 `Column` 是添加任务按钮的源。顶栏按钮和类别托盘在源内部，不采样。
- **浮动层**：紧凑布局里导航胶囊浮在页面上，测得的高度经 `LocalFloatingBarInset` 提供。任务列表、设置各页、整页编辑器把它加进底部内边距，内容可以一直滚到胶囊下面；添加任务按钮放在它上方 16 dp。
- **尺寸** `GlassMetrics`：所有控件（图标按钮、文字按钮、类别芯片、导航项）高 44 dp，主操作 56 dp，托盘内边距 6 dp，图标 22 dp。
- **按压**：不用灰色状态层。`GlassPressIndication` 是全局 `LocalIndication`，从手指处向外泛光（90 ms 亮起、360 ms 退去），光在文字和图标下面；玻璃控件同时放大到 1.06。Material 组件自带的涟漪改为白色（`GlassRipple`）。键盘焦点显示为墨色描边。
- **状态**：选中（导航项、类别芯片、分段、打开的切换按钮）和主按钮 `Prominent` 是更亮更密的透镜 `#FFFDF9` 0.62，文字加粗，仍然透光；`Danger` 是透明玻璃配 `#9A3B30` 文字；开关打开为橄榄色 `#66704F`。
- 托盘里的图标按钮不单独成片（`inTray`），与未选中的芯片一样平放；单独的图标按钮是透明玻璃圆片。
- 玻璃上的次要文字用 `#57534B`，不要用 `mutedText #8C857A`（对比度不足）。

## 5. 小组件

Glance 任务小组件（RemoteViews，无法真模糊桌面）。背景和条目是 `layer-list` drawable（`widget_glass_bg`、`widget_glass_item(_done)`）模拟玻璃。

- 每条任务是自有布局 `widget_task_row`：只有标题（一个带玻璃背景的 `TextView`），不显示步骤（Section）数，以 `AndroidRemoteViews` 整条嵌入，点击切换完成。不要把 `AndroidRemoteViews` 放进 Glance 带背景的容器里：Glance 会把它插到背景那一层，并丢掉同一容器里的其他子项。
- 桌面会把一条任务的视图复用给另一条任务，旧视图上设过的属性会留下来。所以每次绑定都要设全背景、内边距、字号、颜色和文字，不能只给部分任务设置某个属性（例如只在有步骤时显示一行），否则别的任务会带出上一条的内容和字号。
- Task 标题按存储的颜色显示，渐变也一样。Glance 的文字不支持渐变画笔，所以标题是 `TextView`，每个字带自己的 `ForegroundColorSpan`：按小组件实际宽度用 `StaticLayout` 排版（最多两行），取每个字的水平中点在最宽一行中的位置，在等距色标间插值（`widgets/WidgetTitleGradient.kt`）。效果与 Task 页横跨标题的渐变一致，只是逐字而非逐像素。
- 字号取自应用内设置（小 / 中 / 大），类别名与任务标题同号。在第一帧之前读出；不能以默认值起步，否则每次小组件会话开始都会先按“中”画一遍再跳到所选字号。`Content` 的字号参数没有默认值，桌面、系统预览都传入存储的设置。
