## 维护规则

- 现行文档只写现在成立的内容，不写变更过程。改动行为、外观、数据或流程时，在同一个提交里改对应段落；被推翻的内容直接删除，不留“已作废”。
- 变更历史由 git、`CHANGELOG.md` 和 GitHub Release 承担，不另写阶段文档或进度记录。分出前的 Grhinet 历史记录留在 git 历史里。
- 截图、录屏、APK 不入库。
